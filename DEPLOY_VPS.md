# Инструкция по быстрому переносу портала «Технопарк ОАО БЗАЛ» на VPS

В проект встроена полная инфраструктура для мгновенного переноса на любой VPS-сервер (Ubuntu / Debian, включая белорусских хостинг-провайдеров **Hoster.by, beCloud, ActiveCloud** в соответствии с Указом Президента РБ № 60).

---

## Вариант 1: Автоматический деплой через чат (за 1 минуту)

Просто напишите в чат:
> **«Вот данные VPS: IP `XXX.XXX.XXX.XXX`, логин `root`, пароль `...` (и домен `...`, если уже привязан)»**

Скрипт `./deploy-to-vps.sh` автоматически:
1. Соберёт оптимизированный фронтенд (`dist/`).
2. Подключится к вашему VPS по SSH и установит **Node.js 22 LTS**, **PM2** и **Nginx**.
3. Развернёт проект в `/var/www/technopark-bzal` с сохранением базы данных заявок (`data/bzal_server_db.json`), настроек CMS (`data/bzal_cms_db.json`) и загруженных фото (`public/images/uploads/`).
4. Настроит автозапуск при перезагрузке сервера (`pm2 startup systemd`).
5. Настроит Nginx на 80/443 порту (с лимитом до **50 МБ** для загрузки чертежей ЕСКД `.step`, `.dwg`, `.pdf`) и при наличии домена автоматически выпустит бесплатный SSL-сертификат **Let's Encrypt**.

---

## Вариант 2: Запуск одной командой с вашего компьютера

```bash
chmod +x deploy-to-vps.sh
./deploy-to-vps.sh <IP_СЕРВЕРА> root <ПАРОЛЬ> [ваш-домен.by]
```

---

## Вариант 3: Запуск через Docker Compose на сервере

Если на сервере используется Docker:

```bash
docker compose up -d --build
```

Все данные заявок и фотографии CMS монтируются в постоянные тома `./data` и `./public/images/uploads` и не сбрасываются при обновлении контейнера.

---

## Проверка состояния сервера (Healthcheck)

После деплоя статус сервера доступен по адресу:
- `GET http://<IP_или_домен>/api/health` → `{"status":"ok","service":"technopark-bzal-portal","env":"production"}`
